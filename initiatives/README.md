Project Proposals

This folder is used to collect proposals for new projects and changes to existing projects within the working group.

How to submit a proposal

The preferred way to propose a new project or a change to an existing project is to open a Pull Request (PR) that adds a proposal file to this folder.

Create a new Markdown file in this folder.
Describe your proposal, including:
Title — a short name for the proposal.
Motivation — the problem or opportunity you are addressing.
Proposal — what you would like to introduce or change.
Expected impact — why the proposal would be valuable.
Additional considerations — dependencies, risks, open questions, or other relevant information.
Open a Pull Request with your proposal.

Proposals can cover both entirely new projects and significant changes or extensions to existing projects.

Proposal template

You can use the following structure as a starting point:

# Proposal: <title>

## Motivation

<!-- What problem or opportunity does this proposal address? -->

## Proposal

<!-- Describe the proposed project or change. -->

## Expected impact

<!-- What benefits or outcomes do you expect? -->

## Additional considerations

<!-- Dependencies, risks, open questions, alternatives, etc. -->


There is no requirement for a proposal to be fully specified before opening a PR. Early-stage ideas are welcome — the PR discussion is intended to help develop and refine them collaboratively.
